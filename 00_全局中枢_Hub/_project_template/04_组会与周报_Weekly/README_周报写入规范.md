# 04_组会与周报_Weekly —— AI 组会与周报写入规范

> **定位**：本目录属于 **Track B（下游汇报与交付线）**，与科研主线（Track A：`_control/`、`01_论文与协议/`、`02_实验与验证/`、`03_代码与脚本/`）实行**单向只读隔离**。  
> **适用对象**：虚拟机主控 Claude、宿主机 GLM (`glm-5.3` / `glm-5.3-flash`) 及 Antigravity (Gemini 4)。

---

## 一、 子目录命名与历史快照不可篡改原则
1. 每次周会/组会汇报必须在 `04_组会与周报_Weekly/` 下新建独立日期文件夹，格式严格为：
   **`YYYY-MM-DD_汇报主题/`**（例如：`2026-11-22_阶段进展汇报/`）。
2. 往期已经汇报完成的日期文件夹作为历史快照只读留存，**严禁覆写、删除或混杂进本周的草稿**。

---

## 二、 主线单向只读隔离原则（Track A → Track B）
1. **严禁反向污染主线**：制作周报时，AI 只能**只读读取**当前课题的 `_control/00_CONTRACT.md`、`_control/01_PROJECT_STATE.md`、`_control/02_DECISION_LEDGER.md` 以及 `02_实验与验证/` 中**已经运行完毕并落盘**的结果文件。
2. **禁止编造与篡改**：严禁为了做 PPT 好看而顺手改写主线实验脚本、JSON 数据或 `论文初稿.md`；尚未跑完或处于排队状态的实验必须明确标注**「待运行 / 进行中」**，严禁提前编造过渡性结论或占位数字。

---

## 三、 每次组会固定「四件套」交付物规范
在新建的 `YYYY-MM-DD_汇报主题/` 目录内，必须按以下结构写入 4 个标准化文件：

1. **`01-周报大纲.md`**
   - 固定 4 个板块：① 本周核心研究问题与实测结论、② 量化结果与对应数据/代码证据路径表、③ 阻塞点与方法学边界说明、④ 下周执行计划（明确需要导师拍板的 1～2 个关键决策）。
2. **`02-逐页演讲稿.md`**
   - 按 PPT 页码逐页编写，每页必须包含以下 4 栏：
     - **【本页核心结论一句话】**
     - **【数据 / 图表来源路径】**（精确到 `.json` / `.md` / `.png` 相对路径）
     - **【口语化逐字讲稿】**
     - **【导师 / 同门可能追问的边界回答（Q&A）】**
3. **`build_pptx.py` 与 `周报-YYYY-MM-DD.pptx`**
   - 按 `00_全局中枢_Hub/skills/academic-ppt-studio/SKILL.md` 规范生成（可选先让 Claude 将大纲写入 `_bus/ask.md` 后在宿主机调用 `consult glm_heavy` 生成大纲初稿或 `python-pptx` 脚本）。
4. **`03-组会反馈与待办.md`（组会结束后复盘写入）**
   - 组会结束后，把导师和同门的质疑、新点子与修改要求记录在此文件；
   - 由 Claude 主控对照 `_control/02_DECISION_LEDGER.md` 逐条评估影响并标注“是否与已冻结路线冲突”；
   - **重要门禁**：**只有经过人类 PI 本人确认拍板后**，才允许将采纳的新决定升格写入 `_control/02_DECISION_LEDGER.md` 与 `01_PROJECT_STATE.md`，彻底防止组会上的临时发散言论直接冲垮科研主线。

---

## 四、 文风纪律与交付前双检门禁
1. **文风纪律**：
   - 严格遵守 `_control/00_CONTRACT.md` 中的**不宣称清单**（严禁“颠覆认知/准确率/绝对标准答案/恢复了真实三维结构”等违规词汇）；
   - 推荐结合 `00_全局中枢_Hub/skills/anti-defensive-writing/SKILL.md` 用**正向研究条件定界**替代消极自我贬低（例如不写“只是初步合成尝试，价值有限”，改写为“本周期在独立合成开发集上完成了 X 项受控对照测试”），同时将真正的数据/样本边界集中放在每页的【边界回答】或专门的风险页。
2. **交付前必跑双检门禁**（在宿主机 Pebrel 终端执行，全部 PASS 方可汇报）：
   ```bash
   # 检查大纲与讲稿是否存在断链、禁用词或防御腔
   checkms --file "04_组会与周报_Weekly/YYYY-MM-DD_汇报主题/01-周报大纲.md" --file "04_组会与周报_Weekly/YYYY-MM-DD_汇报主题/02-逐页演讲稿.md"

   # 检查生成的 PPTX 是否存在禁用词、超界或空白页
   python3 "../../00_全局中枢_Hub/skills/academic-ppt-studio/scripts/check_pptx_quality.py" "04_组会与周报_Weekly/YYYY-MM-DD_汇报主题/周报-YYYY-MM-DD.pptx"
   ```
