# 引用核验（citation-check）

上游参考文档已随本技能附带于 `references/citation-workflow.md` 与 `references/bibtex-guide.md`。上游的 `arxiv_registry.py` 只查 arXiv，本领域多数文献不在 arXiv，因此改用下面的来源顺序。

## 1. 单条入库

1. 写出这条引文要支持的确切论断。
2. 先查本地：`02_公共资料库_Library/`（公共文献库）→ 当前课题 `01_论文与协议/` → 本地 PDF，`NOTES.md` 只作上下文。
3. 本地没有或要补元数据时联网（需在课题授权范围内）：DOI 用 CrossRef（`https://api.crossref.org/works/<DOI>`）核题名、作者、年份、期刊、卷、页；生物医学文献可再对 PubMed；预印本对 bioRxiv 页面，并检查是否已有正式发表版本（正式版优先）。
4. 打开出处页面核对论断确实出现在原文中，记下页码、图号或节号。
5. 核实后才写入参考文献表；核不到就标“待核”并写原因，交稿前必须清零（交稿前必须清零）。
6. 要下载全文 PDF 时，先列出文件名、来源、大小，等研究者确认。

## 2. 整稿核验

1. 抽出正文全部引用键，与参考文献表比对：缺失、孤立、重复。
2. 每条参考文献按第 1 节第 3 步核元数据，输出核验表：`键 | 题名 | DOI | 核验来源 | 结果（一致/已改/无法核实）| 改了什么`。
3. 抽查论断与出处是否对得上（至少每章 5 条，“待核”条目全查）。
4. 核验表存到 当前课题 `01_论文与协议/citation-audit-<日期>.md`，可交 `consult redteam` 抽查。

## 3. BibTeX（英文稿）

- 条目字段齐全；特殊字符转义；作者名中的重音用 LaTeX 命令。
- 键名统一为 `第一作者姓 + 年份 + 题名首个实词`，无重复。
- 投稿目标期刊若要求将参考文献内联进 `.tex`，最终可使用 `thebibliography` 或由 `.bbl` 内联。

## 4. 不做

- 不凭记忆补文献，不用“看起来合理”的 DOI。
- 不声称“已联网验证”而实际只查了本地。
